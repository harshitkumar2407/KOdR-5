# LLD Java lectures

Each lecture should keep Java source files in its `src` folder and compiled
classes in its `out` folder.

Run the first lecture from the repository root:

```bash
javac -d _LLD_lecture/Lecture_01_Basics/out _LLD_lecture/Lecture_01_Basics/src/Main.java
java -cp _LLD_lecture/Lecture_01_Basics/out Main
```
