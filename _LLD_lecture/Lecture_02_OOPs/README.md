# Lecture 02: OOPs

Topics are organized by package:

- `_01_encapsulation`
- `_02_inheritance`
- `_03_polymorphism`
- `_04_abstraction`

Compile and run every Java file in this lecture from the repository root:

```bash
javac -d _LLD_lecture/Lecture_02_OOPs/out $(find _LLD_lecture/Lecture_02_OOPs/src -name '*.java')
java -cp _LLD_lecture/Lecture_02_OOPs/out Main
```
