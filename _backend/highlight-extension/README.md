# Persistent Text Highlighter

1. Open this folder in VS Code.
2. Press `F5` to start an **Extension Development Host**.
3. In that new window select text, then press `Cmd/Ctrl+Shift+H`.

Highlights are kept in VS Code workspace storage and restored when the workspace is reopened.

## Commands

| Command | Shortcut |
| --- | --- |
| Highlight selection | `Cmd/Ctrl+Shift+H` |
| Choose color | `Cmd/Ctrl+Shift+M` |
| Clear current file | `Cmd/Ctrl+Shift+L` |
| Clear selected highlight | `Cmd/Ctrl+Shift+D` |
| Clear workspace highlights | `Cmd/Ctrl+Shift+G` |

The color can also be set with `highlightExtension.highlightColor` in VS Code Settings.
